## Things I care about

- Clear interfaces that let the important idea stay visible.
- Algorithms that are explainable, testable and fast enough for the real use case.
- Database boundaries that protect data instead of hiding complexity in the client.
- Open source work that leaves the next contributor with a better starting point.
- Sport, discipline and long-term iteration.
